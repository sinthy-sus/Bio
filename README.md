A clean, print-ready personal CV website built with **HTML5 and CSS3**. The project presents professional information in a structured, multi-page résumé layout and includes a button to print or save the CV as a PDF.

---

## 📖 Overview

This project is a browser-based CV for **Induwara Anupriya**, a Software Technology undergraduate. It organizes profile information, technical skills, education, projects, experience, certifications, languages, and extracurricular activities into a professional résumé layout.

The design uses a blue accent palette, responsive styling for smaller screens, and print-specific CSS to make the CV suitable for printing or saving as a PDF.

## ✨ Features

- 👤 Professional profile and contact details
- 🧰 Core competencies and technical skills
- 🎓 Education and certifications
- 💻 Projects and professional experience
- 🌐 Languages and extracurricular activities
- 📱 Responsive layout for smaller screens
- 🖨️ **Print CV** button using the browser's print dialog
- 📄 Print styles designed for A4 pages
- 🔗 Contact and social profile links
- 🎨 Font Awesome icons for contact details

## 🛠️ Technologies Used

- **HTML5** — page structure and CV content
- **CSS3** — layout, styling, responsive rules, and print styles
- **Font Awesome 6.4.0** — icons loaded from CDN
- **JavaScript** — small DOM-ready script; printing is handled by `window.print()`

## 🚀 Getting Started

### Prerequisites

- A modern web browser such as Chrome, Firefox, Safari, or Edge
- Internet access to load Font Awesome icons from its CDN

No package installation, build tools, or backend server are required.

### Step 1: Download or Clone the Repository

```bash
git clone <your-repository-url>
cd Bio-main
```

Replace `<your-repository-url>` with the URL of your GitHub repository.

### Step 2: Open the CV

Open `CV.html` directly in your browser.

Alternatively, use **VS Code** with the **Live Server** extension and choose **Open with Live Server**.

### Step 3: Print or Save as PDF

1. Open the CV page.
2. Click **Print CV** at the bottom-right of the page.
3. In the browser print dialog, select a printer or choose **Save as PDF**.
4. Select A4 paper and check the print preview before saving.

## 🧩 Customization

To personalize the CV, edit `CV.html`:

- **Personal details:** update the name, title, email, phone number, location, and profile links.
- **Profile and skills:** edit the Professional Profile, Core Competencies, and Technical Skills sections.
- **Education and experience:** update qualifications, projects, employment, and dates.
- **Design:** change colors, spacing, typography, and responsive styles in the `<style>` section.
- **Print layout:** adjust the `@media print` rules and `.page` dimensions if needed.

Make sure to replace example or outdated information with accurate details before publishing the CV publicly.

## 🌐 Deployment

This is a static website and can be hosted using **GitHub Pages**:

1. Push `CV.html` and `README.md` to your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose the deployment branch and folder (usually `main` and `/ (root)`).
4. Save the settings and wait for GitHub Pages to publish the site.

If you want the CV to open as the main page of the GitHub Pages site, rename `CV.html` to `index.html` and update any references accordingly.
